# 📊 Bank Loan Analysis Dashboard

## 🧩 Project Overview

This project focuses on analyzing bank loan data to identify key trends in loan approvals, customer profiles, and repayment performance.
It was developed as part of my personal data analytics portfolio to practice data visualization, DAX, and Power BI dashboard design.

## 🎯 Objectives
- Explore patterns in loan approval and rejection across different customer groups
- Understand income, credit history, and employment factors influencing loan decisions
- Build an interactive dashboard that allows stakeholders to drill down into key metrics
- Present clear KPIs and visuals to support data-driven decision-making

## 💡 Key Insights
- Higher approval rates observed among customers with consistent income and positive credit history
- Self-employed individuals showed higher loan rejection rates compared to salaried applicants
- Loan purpose and region significantly impact approval likelihood and repayment trends

## 🛠️ Tools & Technologies
- Power BI – Data visualization and dashboard design
- Power Query – Data cleaning and transformation
- DAX (Data Analysis Expressions) – Custom measures and calculations
